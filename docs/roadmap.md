# Roadmap

!!! warning "Ideas, not commitments"
    This page collects ideas that have come up in the platform repositories. None of them are scheduled and none of them have been built yet. They're here so the direction of the platform is visible in one place.

---

## Ideas under consideration

### :material-account-switch: Riders across multiple organizers

Today each organizer runs an isolated platform, so a rider's account and profile exist separately in each organizer's environment. The idea is to support riders who take part in tours run by **more than one organizer**, without giving up the isolation described in [Security & privacy](security-and-privacy.md).

### :material-package-variant: Generic app distribution

At the moment each organizer's apps are configured for that organizer's backend. The idea is to offer **generic builds of the apps** that can be pointed at any organizer's backend, which would make it easier to bring on a new organizer.

### :material-speedometer: Faster dashboard loading

Ideas for **making dashboard data quicker and cheaper to load** as tours grow, so organizers get the live grid faster.

### :material-card-account-details: Subscription and packaging

Thoughts on how the platform could be **packaged and offered** to organizers.
